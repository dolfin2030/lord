# فروشگاه درب ضد سرقت استاندارد

یک وب‌سایت حرفه‌ای و واکنش‌گرا برای فروش درب‌های ضد سرقت با طراحی مدرن و امکانات کامل.

## 📁 ساختار فایل‌ها

```
door-shop/
├── index.html          # صفحه اصلی سایت
├── css/
│   └── style.css       # استایل‌ها و طراحی ظاهری
├── js/
│   └── main.js         # کدهای جاوااسکریپت و تعاملات
├── images/             # پوشه تصاویر (خالی - باید تصاویر اضافه شوند)
└── assets/             # سایر فایل‌های کمکی
```

## 🎨 ویژگی‌ها

### طراحی ظاهری
- ✅ طراحی کاملاً واکنش‌گرا (Responsive) برای موبایل، تبلت و دسکتاپ
- ✅ پشتیبانی از زبان فارسی و راست‌چین (RTL)
- ✅ استفاده از فونت‌های استاندارد فارسی
- ✅ رنگ‌بندی حرفه‌ای و جذاب
- ✅ انیمیشن‌های نرم و زیبا

### بخش‌های سایت
1. **هدر ثابت** با منوی ناوبری و دکمه تماس سریع
2. **بخش هیرو** با معرفی جذاب و دکمه‌های فراخوان
3. **ویژگی‌ها** نمایش مزایای محصولات (قفل پیشرفته، مقاوم در برابر آتش، عایق صوتی، استاندارد ملی)
4. **محصولات** با قابلیت فیلتر بر اساس دسته‌بندی (کلاسیک، مدرن، لوکس)
5. **درباره ما** با آمار و اطلاعات شرکت
6. **تماس با ما** شامل فرم تماس و اطلاعات ارتباطی
7. **فوتر** با لینک‌های سریع و ساعات کاری

### امکانات تعاملی
- ✅ منوی موبایل همبرگری
- ✅ فیلتر محصولات بدون رفرش صفحه
- ✅ اسکرول نرم به بخش‌های مختلف
- ✅ فرم تماس با اعتبارسنجی
- ✅ نمایش جزئیات محصولات
- ✅ انیمیشن هنگام اسکرول
- ✅ افکت‌های هاور زیبا

## 🚀 نحوه استفاده

### روش ۱: اجرای مستقیم
فایل `index.html` را در مرورگر خود باز کنید.

### روش ۲: استفاده از Live Server (پیشنهادی)
اگر از VS Code استفاده می‌کنید:
1. افزونه "Live Server" را نصب کنید
2. روی فایل `index.html` کلیک راست کرده و "Open with Live Server" را انتخاب کنید

### روش ۳: آپلود روی هاست
تمام فایل‌ها را روی هاست خود آپلود کنید.

## 🖼️ تصاویر

برای نمایش صحیح تصاویر، فایل‌های زیر را در پوشه `images/` قرار دهید:

- `hero-door.png` - تصویر اصلی بخش هیرو
- `product1.jpg` تا `product4.jpg` - تصاویر محصولات
- `about.jpg` - تصویر بخش درباره ما

یا از تصاویر placeholder که در کد قرار داده شده استفاده می‌شود.

## 🎯 شخصی‌سازی

### تغییر رنگ‌ها
در فایل `css/style.css` بخش `:root` را ویرایش کنید:

```css
:root {
    --primary-color: #1a5f7a;      /* رنگ اصلی */
    --secondary-color: #2c3e50;    /* رنگ ثانویه */
    --accent-color: #e74c3c;       /* رنگ تأکیدی */
}
```

### تغییر اطلاعات تماس
در فایل `index.html` بخش‌های زیر را ویرایش کنید:
- شماره تلفن در هدر
- آدرس، تلفن و ایمیل در بخش تماس با ما
- لینک‌های شبکه‌های اجتماعی

### افزودن محصولات جدید
در بخش `products-grid` در فایل `index.html`، کارت‌های محصول جدید اضافه کنید:

```html
<div class="product-card" data-category="modern">
    <div class="product-image">
        <img src="images/product5.jpg" alt="نام محصول">
    </div>
    <div class="product-info">
        <h3>نام محصول</h3>
        <p class="product-desc">توضیحات محصول</p>
        <div class="product-price">
            <span class="price">قیمت تومان</span>
        </div>
        <button class="btn btn-outline" onclick="showProductDetails('product-id')">جزئیات بیشتر</button>
    </div>
</div>
```
